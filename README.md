# English Premier League Historical Data Analysis

Historical English Premier League data analysis using Python, MySQL, pandas, and data visualization.

## Project Overview

This project explores historical English Premier League data using Python and MySQL. It demonstrates a data analysis workflow, from retrieving and storing data to querying, processing, and analyzing football statistics.

## Tools & Technologies

- **Python** — data analysis and scripting
- **MySQL** — relational database and SQL queries
- **Pandas** — data manipulation and analysis
- **SQLAlchemy** — database connectivity
- **Jupyter Notebook** — interactive analysis and documentation

## Project Objectives

- Work with historical Premier League data.
- Store and retrieve data using a MySQL database.
- Analyze football data using Python and SQL.
- Practice data cleaning, data manipulation, and exploratory analysis.
- Develop practical skills in data analytics.

## Skills Demonstrated

- Python programming
- SQL and database connectivity
- Data manipulation with Pandas
- Exploratory data analysis
- Jupyter Notebook workflows

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Configure a local MySQL database and the required credentials.
4. Open the Jupyter Notebook and run the cells in order.

**Note:** Database credentials are not included in this repository. You must configure your own local database connection before running the notebook.
